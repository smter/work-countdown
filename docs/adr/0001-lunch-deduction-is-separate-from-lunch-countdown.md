# 午休的扣除开关只管工时，不管午休倒计时

「扣除午休」决定午休区间算不算进当天工时，从而决定目标下班时间；卡片上的午休倒计时只看午休区间的起止时刻，永远按钟表走。

这两个问题看着是同一件事，实际不是。作者的真实情况是：考勤机器人按纯钟表差算，所以「扣除午休」默认关掉；但他仍然想知道「离午休还有多久」。如果把两者绑在一个开关上，关掉扣除就必须同时失去午休倒计时。

**考虑过的选项**

- 一个开关同时管显示与扣减：语义简单，但关掉扣除的人会失去午休倒计时，而这恰恰是他唯一想要的那半个功能。
- 只保留扣除：午休倒计时整行消失，卡片少一行信息。

**后果**

午休区间填错时（例如 `25:00`），午休倒计时整行自动不显示，而工时计算照样按班次算——两者各自失效，互不牵连。改这里的人要知道：这条独立性是故意留的，不是漏了联动。
