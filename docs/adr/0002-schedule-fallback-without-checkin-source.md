# 没有考勤对话时按班次推算，不显示「还没打卡」

接了考勤对话却读不到今天的上班打卡，是「你现在还没打卡」，这是一条信息。没接考勤对话，是「这台机器不可能知道」，显示同样的话就是噪音。

所以判断分两步：先看有没有数据源。没有数据源时，把上班时间当作上班时刻，照常给出目标下班时间，卡片上永远不出现「还没打卡」，只会说「未接入飞书，按班次时间计算」。有数据源时才走真正的打卡判定。

**考虑过的选项**

- 永远按打卡判定：最诚实，但新用户第一次打开就顶着「还没打卡」，什么都干不了。
- 首次引导强制接入飞书：把可选数据源变成必需，和「发给同事、填个上下班时间就能跑」的目标冲突。

**后果**

同一个状态词的含义依赖「是否接入飞书」，卡片文案与这个判断强耦合。看代码时不要以为 `还没打卡` 是默认状态——它是有数据源时才可能出现的状态。
