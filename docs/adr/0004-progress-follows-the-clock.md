# 进度条是钟表的进度，不是在岗时长的进度

固定班次下，进度从班次的上班时间算起，到目标下班时间为止；只有弹性工时才从实际上班打卡算起。

于是 09:00–18:00 的班次里，10:00 才打卡的人一打开卡片，进度条已经走了 11%，而下面那行写着「已工作 00:00」。看着像矛盾，其实是两个问题：进度条回答「今天还剩多久」，在岗时长回答「今天已经干了多久」。

**考虑过的选项**

- 固定班次也按实际打卡算进度：两把尺子合成一把，但进度条就不再表示「今天还剩多久」，还会和它上面那个始终指向固定下班时间的大号倒计时对不上。
- 去掉进度条，只留倒计时：横条上那条细进度是「一眼看到还剩多少」的主要视觉，去掉后卡片只剩数字。

**后果**

别把「迟到时进度不归零」当 bug 修。真要改，改的是「进度条想问哪个问题」——并排的倒计时和在岗时长会跟着一起变意思。
