## 怎么开

双击 `index.html`（或用 `pwsh -File open.ps1`）。不需要构建、不需要装依赖，字体直接从 `../../fonts` 读。

底部那条浮条是原型工具，不属于设计本身：

| 控件 | 作用 |
|---|---|
| `‹ A 海报 ›` / ← → | 切换三个变体（URL `?variant=`） |
| 下班 / 午休 | 场景：文案与目标时刻（`?scene=lunch`） |
| 四个色点 | 试不同强调色下的斜纹（`?acc=red`） |

额外参数：`?t=8` 直接停在剩 8 秒（看临界态）、`?t=0` 看到点、`?anim=0` 关掉动效拍静态帧。

## 结论（2026-11-05）

**A 入选**，B/C 只作对照留着。落地的是 A 的版式（上下斜纹横幅 + 巨号读数），并采纳了这些决定：午休沿用同一套只换文案、斜纹跟随强调色、不放大窗口、告警态不放 T-mm:ss 伴读。实现见 `src/Widget.cs` 的 `PaintAlert` 与 ADR 0006。

## 三个变体

- **A · 海报**：上下两条斜纹横幅夹住中央巨号读数，扫描线 + 四角括号 + 刻度进度带。最接近参考图。
- **B · 控制台**：左侧竖排斜纹轨（`ALERT` 竖标签），逐位数字格，三列遥测（目标 / 进度 / 剩余）+ 尺标与 `WARNING` 水印。信息密度最高。
- **C · 贴纸字**：满幅斜纹铺底，标签与读数做成贴上去的黑色标牌，白字黑描边。最像 EVA 标题卡，最张扬。

三个变体共用同一套强度阶梯：常态 → 最后 60 秒（斜纹加速、辉光变强）→ 最后 10 秒（读数心跳、卡片外圈起光）→ 到点（整卡切达标绿 + `已达标` 浮层）。

## 和真程序的差距（别当成实现细节）

- 真程序是 .NET Framework + WinForms 的 GDI 绘制；浏览器里的字形抗锯齿、渐变和阴影不完全一致，字号按 DIP 折算。
- 字体用的是同一份内嵌子集（Maple Mono NF CN ExtraBold / Sarasa Mono SC SemiBold），但浏览器会额外做亚像素排版。
- 尺寸严格按 `DesignExpandedW/H = 280×186`（含午休行 210）；没有假装它能更大。
- 旋转门式动画时长按能看清来配；真机要实现时再对齐 `animT`（15ms tick）与 `reducedMotion`。

## 还没定的事
